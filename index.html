O projeto inclui um painel administrativo intuitivo para que a equipe da FEMCO possa manter o site atualizado sem depender de um desenvolvedor para alterações rotineiras.


  • Cadastrar novas obras
  • Adicionar e remover fotos das galerias
  • Editar textos institucionais
  • Atualizar produtos e soluções
  • Alterar informações de contato
  • Gerenciar conteúdos através de interface amigável
  • Publicar atualizações de forma independente

Ao final do projeto será realizado um treinamento para utilização das principais funcionalidades do sistema.
